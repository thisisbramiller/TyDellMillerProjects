## Description

## Features

- Homepage, Services Page, Portfolio Page, Contact Page, About Page, and Blog
- Integration with Stripe for handling payments
- Integration with Calendly for scheduling appointments
- Integration with Formspree/AWS Lambda for handling contact form submissions
- Static site hosted on AWS S3 with CloudFront for global content delivery
